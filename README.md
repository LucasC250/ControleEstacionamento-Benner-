# Carro Bem Guardado

Projeto desenvolvido em C# com ASP.NET Core MVC para controle de estacionamento.

O sistema permite registrar a entrada e saída de veículos, acompanhar os veículos que estão estacionados, cadastrar tarifas com períodos de vigência e calcular automaticamente o valor a ser pago de acordo com o tempo de permanência.

## Tecnologias utilizadas
- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQLite
- HTML, CSS e JavaScript

## Como executar o projeto

Para executar o projeto, é necessário ter o .NET SDK instalado na máquina.

1. Clone o repositório:
```bash
git clone [https://github.com/LucasC250/ControleEstacionamento-Benner-.git](https://github.com/LucasC250/ControleEstacionamento-Benner-.git)

```

2. Abra pelo Visual Studio:
Entre na pasta do projeto  e clique duas vezes no arquivo **`ControleEstacionamento.slnx`** para abrir a solução completa.
 <img width="374" height="593" alt="image" src="https://github.com/user-attachments/assets/4d1af872-5fb6-4add-a1c9-864f1dca6798" />


Depois é só rodar o projeto apertando F5 ou clicando no botão de iniciar.

4. Ou execute pelo terminal:
Entre na pasta onde está o arquivo `.csproj` e rode:

```bash
dotnet restore
dotnet run

```

Depois de executar, o terminal vai mostrar o endereço local da aplicação. Basta copiar e abrir no navegador.

## Sobre o projeto

O objetivo foi desenvolver uma aplicação simples para facilitar o controle de um estacionamento, aplicando conceitos de C#, MVC, banco de dados e regras de negócio.
